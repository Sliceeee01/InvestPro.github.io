## Что такое Bootstrap?

**Bootstrap** — это бесплатный CSS-фреймворк (набор готовых стилей и компонентов), разработанный компанией Twitter.

### Простыми словами:

Bootstrap — это огромная библиотека готовых стилей, которые вы просто подключаете и используете. Вам не нужно писать CSS с нуля для кнопок, карточек, сеток и других элементов.

---

## Как подключить Bootstrap

```html
<!-- В <head> -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Перед </body> -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>

```

## Основные компоненты Bootstrap
| Компонент | Описание | Пример кода |
|-----------|----------|-------------|
| **Кнопка** | Синяя красивая кнопка | `<button class="btn btn-primary">Кнопка</button>` |
| **Карточка** | Белая карточка с тенью | `<div class="card">...</div>` |
| **Сетка** | 12-колоночная адаптивная система | `<div class="row"><div class="col-6">...</div></div>` |
| **Навигация** | Адаптивное меню-бургер | `<nav class="navbar">...</nav>` |
| **Форма** | Стилизованные поля ввода | `<input class="form-control">` |
| **Модальное окно** | Всплывающее окно | `<div class="modal">...</div>` |
| **Аккордеон** | Раскрывающиеся панели | `<div class="accordion">...</div>` |
